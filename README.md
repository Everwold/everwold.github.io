# EVERWOLD

The website of EVERWOLD, a pixel MMORPG in development. A static page for GitHub Pages: no build step, no tracking, fonts hosted here.

- `index.html`: the whole page
- `assets/`: fonts (OFL), stills and short gameplay loops from the current build
- `og.jpg`, `favicon.png`, `apple-touch-icon.png`: link preview and icons

Publish: push this folder to the `main` branch of `everwold/everwold.github.io`, then turn on Pages (Settings → Pages → Deploy from branch → main / root).
